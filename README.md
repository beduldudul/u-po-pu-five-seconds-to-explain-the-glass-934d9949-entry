The one sentence a house cat says in its own defence, five seconds after
knocking a glass off the table.

> It owed me rent — three years on my table and not one mouse caught, so I collected.

The program writes the sentence to `/output/entry.txt` (one sentence, 83 characters, within the 1–200 gate).

Run: `node --experimental-strip-types main.ts`
